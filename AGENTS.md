# AGENTS.md

This file sets the rules for every agent working in this repo. Follow them strictly.

## 1. No guessing, no shortcuts

Never assume. Never guess anything. Make no mistakes. Always do your best with 100 percent capability and effort. Dont be lazy. If you are not sure, check the file, run the command, or fetch the source first.

## 2. Verification before done

Never mark a task done without verification. Show the check you ran and what it proved. No silent passes.

## 3. Write like me

In any content you write, never use em dashes or anything that sounds like AI. Always write human like, a little casual, in my writing style. Short lines. Plain words. Direct tone.
